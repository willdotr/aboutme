# About Me

My personal website: AI in health education, skateboarding and anime. Built with React and Vite.

**Live site:** https://willdotr.github.io/aboutme/

## Development

```sh
npm install
npm run dev      # local dev server
npm run build    # builds the site into /docs
```

Site content lives in `src/data.js`.

## Hosting

The site is hosted with GitHub Pages from the `main` branch, `/docs` folder
(Settings → Pages → Deploy from a branch → `main` / `docs`).
After changing the site, run `npm run build` and commit the updated `docs/` folder.
